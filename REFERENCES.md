# References

These references document neighboring and component techniques. SparseEcho does not use them as evidence that SFPTI is legally novel.

1. Xiao Li, Joseph K. Bradley, Sameer Pawar, Kannan Ramchandran. **SPRIGHT: A Fast and Robust Framework for Sparse Walsh-Hadamard Transform.** arXiv:1508.06336, 2015. https://arxiv.org/abs/1508.06336

2. Mahdi Cheraghchi, Piotr Indyk. **Nearly Optimal Deterministic Algorithm for Sparse Walsh-Hadamard Transform.** arXiv:1504.07648, 2015. https://arxiv.org/abs/1504.07648

3. Wang Hao, Yuan Zhonghao, Chi Yonggang, Zhang Kuang, Tan Chenxing, Yu Jiaxing. **WHTDM: Walsh-Hadamard Transform Division Multiplexing for Doubly-Selective Channels.** arXiv:2605.14482, 2026. https://arxiv.org/abs/2605.14482

4. Weibin Ni, Lei Sun. **Hadamard Sensing Channel: Deterministic Artifact Suppression for Quantum Sensors.** arXiv:2608.06119, 2026. https://arxiv.org/abs/2608.06119

5. **Hadamard, Hadamard-Walsh and other acquisition orderings for physical compressive measurements.** Representative experimental discussion: arXiv:2210.11483, 2022. https://arxiv.org/abs/2210.11483

The binary-reflected Gray code and Walsh-Hadamard transform are classical constructions and are treated as such throughout this repository.
