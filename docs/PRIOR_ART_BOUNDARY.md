# Prior-art boundary

SparseEcho uses established mathematical and engineering tools. The project does not present the following as inventions:

- Walsh-Hadamard transforms and FWHT;
- binary-reflected Gray ordering and natural-binary ordering;
- sparse Walsh-Hadamard / sparse Fourier recovery;
- linear hashing, list recovery and peeling/CLEAN-style subtraction;
- CFAR detection;
- least-squares erased-sample reconstruction;
- moment-constrained interpolation;
- query-controlled physical sensing in the broad sense.

**Spectrally Factorized Physical-Time Inversion (SFPTI)** names the construction used in this repository: physical execution schedule, temporal-nuisance representation and fiber-aware inversion are designed as one measurement/reconstruction problem.

The public implementation explores low-generator physical-time embeddings, explicit transform-domain temporal fibers, fiber-tail scheduling budgets and reconstruction logic that consumes those structures.

This description is an engineering/research boundary, not a patentability opinion or freedom-to-operate analysis.
